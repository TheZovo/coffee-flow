Команда

Список барист

Карточка бариста

Здесь задается, кто может получать смены и работать в бариста-боте. Telegram ID больше не нужен: запись привяжется автоматически при первом входе баристы в бот по username, а если его нет, по точному имени.

Username лучше указать, тогда привязка пройдет автоматически и без ошибок. Если username не заполнен, бот попробует привязать баристу по точному совпадению имени при первом входе.

Если бариста выключен, он остается в списке, но больше не сможет работать с заказами, пока вы снова не включите доступ.

Смены барист

Редактор смены

Укажите точное начало и конец смены. Доступ к бариста-боту будет открыт только в этом интервале.

Время сохраняется с учетом локальной таймзоны приложения. Пересекающиеся активные смены для одного бариста не допускаются.
